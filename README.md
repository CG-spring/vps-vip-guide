## 为什么需要一台 VPS

很多人把「买 VPS」和「买机场」混为一谈，其实它们是两种东西：

- **机场** 是把别人搭好的节点打包卖给你，开箱即用，但带宽、规则、稳定性都掌握在机场主手里。
- **VPS** 是一台你拥有 root 权限的云服务器，你可以在上面跑代理、建站、做爬虫、挂机器人、跑 Docker 全家桶——它是「基础设施」，而不是「成品服务」。

当你开始在意隐私、流量、可定制性时，VPS 是更长期的方案。

## VPS vs 机场：到底怎么选

| 对比项 | VPS | 机场 |
|--------|-----|------|
| 流量 | 基本不限（看带宽） | 按月配额 |
| 带宽 | 独享/共享，可控 | 共享，晚高峰易拥堵 |
| 稳定性 | 自己掌控，依赖厂商 | 依赖机场主，说没就没 |
| 可玩性 | 高，可跑任意服务 | 低，仅代理 |
| 成本 | 年付 $60 起 | 月付 $10 起 |
| 技术门槛 | 需基础 Linux | 零基础 |

**结论**：重度 / 长期 / 技术向用户选 VPS；只想一键翻墙、不想折腾的轻度用户，机场更省心。

## 机房与线路：决定速度的关键

同样的配置，放在不同机房，体验天差地别。对国内用户，核心是「回程线路」——也就是数据从机房回到你手里的那段路。

### 按延迟（Ping）排序

1. **香港** — 30–50ms，物理距离最近，首选但贵
2. **日本（东京/大阪）** — 50–80ms，游戏加速友好
3. **韩国（首尔）** — 50–70ms，韩区内容/游戏
4. **新加坡** — 60–100ms，东南亚业务
5. **美国（洛杉矶/圣何塞）** — 150–200ms，大流量首选

### 按三网优化程度排序（国内可用带宽）

- **CN2 GIA / 9929 / 4837** 等优化线路 >> 普通直连 >> 绕路国际
- 简单判断：晚高峰（20:00–23:00）还能满速的，基本是优化线

### 机房选择口诀

- 要快选 **香港 / 日本**
- 要大流量选 **美国（KVM + 大带宽）**
- 要便宜选 **美国 / 新加坡 年付**
- 要稳选 **有 CN2 GIA 回程** 的厂商

## 服务商类型与代表厂商

1. **大厂免费/低价档（练手、测试）**
   - Oracle Cloud 永久免费机（4 台 ARM + 2 台 AMD）
   - AWS / GCP / Azure 新用户试用金
   - 优点：稳、免费用；缺点：免费档容易被风控、误封

2. **高性价比独立厂商（长期主力）**
   - RackNerd / CloudSilo / VirMach：年付 $10–20 的入门 KVM
   - HostDare / JustHost：对国内三网优化较好的中端
   - 优点：便宜、可年付；缺点：工单慢、存在超售

3. **优化线路 premium 厂商（要速度）**
   - DMIT / 搬瓦工(BandwagonHost) / 皓锋：CN2 GIA 回程，晚高峰稳
   - 优点：速度顶级；缺点：价格是普通档 3–5 倍

## 选购 Checklist

买之前逐项确认，避免踩坑：

- [ ] **虚拟化**：优先 KVM（性能隔离好），OpenVZ 已淘汰
- [ ] **机房位置**：根据上面「线路口诀」选
- [ ] **回程线路**：问清是否 CN2 GIA / 9929
- [ ] **流量政策**：是「不限量限速」还是「限量不限速」？
- [ ] **退款政策**：是否支持 7 天无理由 / 按小时计费
- [ ] **支付方式**：支付宝 / 微信 / 信用卡 / 加密货币
- [ ] **工单响应**：看评测里的真实工单速度
- [ ] **是否 NAT**：NAT 机便宜但通常无独立 IP

## 安全加固与提速

部署完别急着用，先做这几步：

1. **改 SSH 端口 + 禁用密码登录**：只用密钥
   ```bash
   sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
   systemctl restart sshd
   ```
2. **开防火墙**：只放行 22/443 等必要端口（ufw / firewalld）
3. **开启 BBR 拥塞控制**（提速明显）：
   ```bash
   echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
   echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
   sysctl -p
   ```
4. **定期更新**：`apt update && apt upgrade -y`
5. **监控流量**：防止被刷爆，`vnstat` 是好帮手

## 成本精算：月付还是年付

| 付费方式 | 典型单价 | 适合人群 |

| 月付 | $5/月 | 试用、短期、不确定能否用 |

## 常见问题 FAQ

**Q：为什么刚买的 VPS 速度很慢？**
A：多半是回程线路差或晚高峰拥堵。换 CN2 GIA 厂商，或换机房（香港/日本优先）。

**Q：IP 被墙了怎么办？**
A：部分厂商支持免费换 IP（如 DMIT、搬瓦工）；否则只能加钱买独立 IP 或换机。

**Q：VPS 可以用来建站吗？**
A：可以，但注意部分厂商 TOS 禁止某些用途，建站前看清楚条款。

**Q：免费 Oracle 值得搞吗？**
A：值得当备用机练手，但风控严、容易误封，不建议做主力。
